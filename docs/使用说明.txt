QEMU 3dfx WinHelper 0.3.0 · QEMU 11.1.2 x64

开始使用
完整解压压缩包，双击 qemu-3dfx-winhelper.exe。无需安装运行环境。
点击“新建”，选择 Windows XP 安装 ISO，创建后启动即可。
首次安装勾选“仅本次优先从光盘启动”；声卡默认使用 AC97，可在配置中关闭。

鼠标与光盘
运行时可以用“鼠标”开关在 USB 和 PS/2 之间切换。
USB 鼠标可移出虚拟机窗口；PS/2 鼠标使用 Ctrl + Alt + G 释放。
选择另一张 ISO 后点击“挂载 / 保存光盘”，即可换盘。
guest-tools.iso 与主程序放在一起；点击“工具盘”再挂载即可使用。
工具盘包含 3dfx / OpenGL 工具及测试程序，AC97 驱动请按客体系统单独准备。

虚拟机文件
machines 文件夹保存虚拟机配置、硬盘、快照和日志。
bin 文件夹保存程序运行所需的文件，请保留完整内容。
关闭管理器不会关闭运行中的虚拟机。
搬迁前请关闭全部虚拟机，然后复制整个工具文件夹。

快照与备份
先在虚拟机内正常关机，再创建、恢复或删除快照。
恢复前自动保留当前状态快照。快照只保存磁盘内容。
“导出当前磁盘”可以生成独立 qcow2 备份。

运行要求
Windows 10 2004 或更新版本、Windows 11，x64。
Windows XP 安装光盘由用户自行提供，不包含在压缩包中。

直通显卡驱动安装
装完 XP 后请加载 guest-tools.iso 运行 install.cmd
然后去 C:\QEMU3DFX\OpenGL\ 打开 Test3D.exe
如果能看到 3 个转得很快的齿轮，说明 主机显卡功能安装成功。
后续要把  C:\QEMU3DFX\OpenGL\opengl32.dll 放到目标游戏旁边
就可以愉快的玩老游戏了
